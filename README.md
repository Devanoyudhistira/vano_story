# CMS Blogging Platform -- Vano-story

A content management system (CMS) for creating, editing, managing, and publishing blog posts through a rich text editor.

## Overview

Vano_story is a blogging CMS designed to simplify content creation and management. It provides an interface for writing articles,and managing published posts without editing source code directly.

Built as a portfolio project to demonstrate full-stack development, content management, and rich text editing.

## Features

- **Rich Text Editor** — Write and format blog posts with an intuitive editing experience.
- **Post Management** — Create, edit, delete, and manage your story.
- **Easy autentication** — Easy and secure Sign as a writer or a reader with google account.
- **Content Organization** — Organize posts using categories or tags in the main page.
- **Responsive Design** — Access the CMS across desktop and mobile devices.

## Tech Stack

- **Fullstack framework:** next js
- **Styling:** Tailwindcss & shadcn
- **Database:** Mongodb atlas
- **Authentication:** Supabaseauth
- **Text Editor:** TipTap

## Key Highlights

- Implemented a content management That can be publish and read by all people in the world.
- an easy and comfortable to read blog
- Integrated a rich text editor for structured article creation.
- Designed a reusable and maintainable user interface.
- A Secure and easy autentication using google as a provider
